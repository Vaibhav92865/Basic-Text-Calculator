# 🧮 Basic Text Calculator

A simple command-line calculator built using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used

- Python 3

## How to Run

```bash
python calculator.py
```

## Example

```
Choose Operation
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter first number: 10
Enter second number: 5
Enter your choice (1-4): 1

Answer = 15
```
